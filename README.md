# 戦国ガイド試作（長井市5館）

地域の戦国を説明するサイトの試作。Markdown CMS の型（Markdown＋frontmatter → build → JSON → 表示）で作る。
データの正本は Markdown ファイル。城館データはゲーム『奥羽一生録』と共通（正本は1つ、ゲームはID参照）。

## 状態（2026-11-01）
- ローカルのみ。リポ作成・公開はしていない（公開は本人の承認後）。
- build: `python3 scripts/build.py` → `dist/`（index.html / app.js / data.json / Leaflet自己ホスト）。
- 検証: build のバリデーション（ID・参照・ファイル名）通過、data.json の相互リンク・年表・領地を確認、ローカルHTTPで 200 応答を確認。

## 中身
- `content/places/` 城館5件（四十八館14〜18: 白山森館・正福寺館・時庭館・片倉館・横沢山館）。座標は地理院地図・OSMで取り直し、精度を各ファイルに明記。元サイトの文章・写真・座標は不使用。
- `content/people/` 人物8人（大町家継・大町頼明・安久津甚内・片倉右京・片倉図書介＋参照: 政宗・成実・片倉景綱）。人物側の `stays` が正本で、城館側の「この城にいた人物」は build が自動生成（双方向リンク）。
- `content/organization/date-house.md` 伊達家の仕組み（組織図ツリー＋地図画像背景の組織図＋役職用語15語）。人物の役職語から用語アンカーへリンク。
- 城館ごとの年表: 成実の年表（ネオ成実三昧）と同じ型。帯＝領主の時代（長井→伊達→蒲生→上杉、時間比例）、表＝出来事＋「その頃この城にいた人物」（stays から自動判定）。
- 領地図: 時代ボタンで色分け切替。伊達の時代は中の領主（氏）別に城館中心の推定円、その他の時代は全体をその家の色に。範囲・ピンを押すと紹介へジャンプ。範囲は推定（目安）と明記。

戦国ガイド試作 ― 長井市の城館
置賜の戦国を、城館・人物・年表・領地の地図で読む試作ページです。座標は地理院地図とOpenStreetMapで取り直し、文章はすべて書き下ろし。領地の色分けは境界の史料がないため、城館を中心とする推定の目安です。
目次
試作（長井市5館）。データの正本は Markdown ファイルで、城館データはゲーム『奥羽一生録』と共通です。
座標の確かさ（凡例）
  • 遺跡の位置を特定 ― 調査や現地の手がかりで、城館跡の場所を特定できた座標です。
  • 現地写真の位置情報から取得 ― 本人が城跡で撮った写真の位置情報（GPS）から入れた座標です。
  • 字・集落からの近似 ― 字（あざ）や集落の位置からの近似です。実際の跡とは少しずれることがあります。
  • 地区レベルの近似 ― 地区のおおよその位置です。目安として使います。
  • 未設定 ― 座標はこれから入れます。説明は先に公開しています。
時代を選ぶと、地図の色分けがその時代の領主に切り替わります。色のついた範囲やピンを押すと、その城館の紹介へ飛びます。
